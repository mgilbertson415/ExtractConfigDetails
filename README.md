# ExtractConfigDetails
## SW macro to read configuration details from all parts and assemblies in a given folder, and write to csv.

Purpose: project-oriented macro to backfill null instance titles, should should be ConfigName(SuffixlessFamilyName)

So routine is to open (in Document Manager) each part/assembly in a folder, and read config names. For each config, output filename, config name, and concatenated instance title. More extraction details will be added later if they are needed.
